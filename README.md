# inbox-wrassler
*personal gmail sidebar add-on with quick links to search*

do you ever let your email inbox get completely out of control and you're completely overwhelmed and you want to just delete everything but you still kinda sorta need to skim the emails? this gmail sidebar add-on will:

- count the number of emails by domain and gmail labels (scheduled once a day) 
- provides one click search links of all emails in the inbox associated with that domain 

(yes i made claude write this and yes it is hideous but it's working)
